  <Card title="Rust holds the truth">

  </Card>
  <Card title="JS just renders">
    Your components subscribe to values and push user input back. Nothing else.
  </Card>
  <Card title="Four adapters">

    works too.
  </Card>
  <Card title="Typed across the bridge">

    JS side knows what each key gives back.
  </Card>
